# Contributing to Polar Dash

Thanks for helping improve this Three.js animal endless runner.

## Local setup

1. Install Node.js and npm.
2. Run `npm ci` from the repository root.
3. Run `npm run dev` to play locally.
4. Run `npm run build` before opening a pull request.

## Suggested contributions

- Improve character animation or accessibility without changing existing controls unexpectedly.
- Add mobile input and performance tests.
- Fix obstacles, collisions, energy pickups, and gameplay bugs.
- Add screenshots or short recordings captured from the actual game, not concept art.

## Pull requests

Describe the change, include before/after screenshots for visual updates, explain how you tested it, and keep changes focused. Do not commit API credentials, paid assets without redistribution rights, or generated build output.

For sensitive vulnerabilities, follow [SECURITY.md](SECURITY.md) rather than filing a public exploit report.
