# Penguin Ice Adventure ❄️

A playable Three.js ice-platform adventure with a procedural penguin, walk and jump controls, ice obstacles, a lion enemy and collectibles.

## Run locally

```cmd
npm install
npm run dev
```

Open http://localhost:5173/.

## Controls

- A / D or left / right arrows: move
- Space or up arrow: jump
- R: restart
- Mobile: on-screen buttons

This is a stylized playable prototype rather than the photorealistic promotional concept image.
