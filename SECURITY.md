# Security Policy

## Supported versions

This is an evolving playable prototype, not a production-certified mobile game. Security fixes are targeted at the current `main` branch.

## Reporting a vulnerability

Please **do not post exploit details publicly**. Use GitHub's private vulnerability reporting feature on this repository if enabled. If it is unavailable, contact the maintainer through their GitHub profile without sharing sensitive reproduction details in public issues.

Useful report details include affected file/version, reproduction steps, impact, and suggested mitigation. Never include user secrets or other people's personal data.

## Player data

The web prototype may save local game progress in browser storage. Review [PRIVACY.md](PRIVACY.md) for the current privacy notes. Android distribution requires a separate privacy and store-compliance review before release.
